# 管理設定の変更記録

既存ticketへ貼り付けて使用する。完了記録と実環境の証跡は組織内に保存する。

## 申請

- 対象provider／account／repositoryと設定のURLまたはID:
- 変更する設定名:
- 変更前の値・取得元・取得時刻:
- 変更後の値:
- 変更理由:
- 新しく権限を使える人・workflowと起こり得る被害、その成立条件:
- Build／releaseへの影響:
- 戻す値、戻す判断条件、担当者:
- 申請者・実行予定者:

## 承認

- 申請者・実行者とは別の承認者:
- 対象と変更後の値を確認した結果:
- 承認／却下と時刻:

## 実行と別人による確認

- 実行者・実行時刻:
- Providerの実行記録への参照（actor、対象、操作、時刻）:
- 変更後の実設定・取得元・取得時刻:
- 確認者・確認時刻:
- 承認内容との一致／不一致／未確認／取得失敗:
- 未解決事項・担当者・対応期限:

## 緊急変更の場合

- Incident IDと事前承認を待てない理由:
- 一時変更の期限・事後確認の期限:
- 独立した確認者・判断時刻:
- 継続／復元の判断と実行結果:
- 通常変更または期限付き例外への引継ぎ:

秘密情報を含めない。空欄や取得失敗を確認済みと扱わない。
