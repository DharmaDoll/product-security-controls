# MITRE ATT&CK Registry

This registry baseline is used for attacker-behavior mappings. It is not a
compliance checklist.

- Scope: Enterprise ATT&CK
- Content version: `v19.1`
- Source: [MITRE ATT&CK version history](https://attack.mitre.org/resources/versions/)
- Machine-readable registry: [`registry.json`](registry.json)

Mappings must use identifiers present in this pinned release and explain the
evidence and limitation of the relationship.

The registry contains active Enterprise ATT&CK objects from the pinned official
STIX bundle. Revoked and deprecated objects are intentionally excluded so that
new mappings cannot silently target retired behavior.
