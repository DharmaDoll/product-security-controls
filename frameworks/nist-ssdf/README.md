# NIST SSDF Registry

This registry baseline is used for secure software development practice
mappings. It is not a certification or compliance assessment.

- Publication: NIST SP 800-218
- Version: `1.1`
- Publication year: `2022`
- Source: [NIST SP 800-218](https://csrc.nist.gov/pubs/sp/800/218/final)

Mappings must identify the specific practice or task and state whether the
control supports or provides evidence for it.
